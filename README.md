# The World in One Day — Tuesday 24 November 2026

A six-story newspaper front page, led by Asian stocks surging after Nvidia CEO Jensen Huang's return, South Korea scrambling jets over Russian planes near Ulleungdo, and Iran claiming three tankers hit mines near Hormuz. The supplied front page is preserved as-is, with no redrawing, headline changes, or added stories.

## Run it

With Node.js 22 (22.18 or later for direct TypeScript execution):

```sh
node main.ts
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The default output is `/output/entry.png`. The program validates the image signature and verifies the written file against the source SHA-256.
